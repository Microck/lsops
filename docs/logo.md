# logo

the readme uses [lsops.png](../.github/assets/lsops.png), generated with the
built-in image generation tool. the mark combines a terminal prompt with a list
of commands. it uses white on black and has no text.

## generation prompt

```text
Use case: logo-brand
Asset type: final repository logo for lsops, a small command-line tool that gives coding agents a user-curated catalogue of available CLI tools.
Primary request: Create one distinctive, professional monochrome symbol. Combine the idea of a terminal prompt with a compact index of commands in a single coherent geometric mark. A bold right-facing chevron aligned with two or three short horizontal strokes, with deliberate negative space and an original silhouette. Make it feel like a precise small Unix utility.
Style: flat, crisp, vector-like solid white geometry. Optical balance, consistent visual weight, recognizable at 32 pixels.
Composition: one centered symbol in a square image, occupying about 65% of the canvas, generous even black margins.
Color palette: pure white #ffffff mark on a uniform pure black #000000 background.
Constraints: symbol only, no text, no letters, no wordmark, no rounded app tile or enclosing border, no gradients, no shadows, no glow, no 3D, no mockup, no extra decoration, no multiple concepts.
```
